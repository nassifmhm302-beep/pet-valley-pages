# بيت فالي — نسخة GitHub Pages الثابتة

صفحة عربية تعريفية ثابتة مبنية من ملفات الموقع المرفق، ومهيأة للنشر عبر GitHub Pages. الواجهة RTL ومتجاوبة مع الجوال، وتستخدم صورًا محلية حتى لا تعتمد على تحميل الصور من مواقع خارجية.

## حدود هذه النسخة

GitHub Pages يستضيف ملفات ثابتة فقط. لذلك لا تتضمن هذه النسخة قاعدة البيانات أو خادم Next.js أو وظائف الخادم من المشروع الأصلي. الحجز الإلكتروني، المتجر وسلة الشراء، الحسابات وتتبع الطلبات، نماذج الإرسال، ولوحة الإدارة غير فعالة هنا.

لم تُدرج أرقام الهاتف أو البريد أو العنوان أو ساعات العمل؛ لم تكن هذه البيانات معتمدة في الملفات المرفقة. كما أن الأوصاف والصور تجريبية/توضيحية، ويجب التحقق من توفر الخدمات ومعلومات التواصل قبل استخدامها كبيانات تشغيلية.

## النشر

بعد إضافة هذا المستودع إلى GitHub، اختر **Settings → Pages → Build and deployment → Source: GitHub Actions**. يدفع سير العمل الموجود في `.github/workflows/pages.yml` محتويات الفرع `main` إلى GitHub Pages تلقائيًا.
